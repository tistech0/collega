# PDF local (partie B, après revue) : version = job publié, copie datée par l'app, téléchargement vérifié, pdfrx 1.0.103

> Le PDF importé est relu dans l'app. Serveur : services/imports.current pdfs DISTINCT ON college id, dernier job gener…

Le PDF importé est relu dans l'app. Serveur : services/imports.current_pdfs (DISTINCT ON college_id, dernier job generation_complete dont le fichier existe) alimente pdf_version (id du job, pas pdf_hash nullable) et pdf_size dans GET /v1/colleges, et GET /v1/colleges/{id}/pdf (FileResponse, Range/206, 404 COLLEGE_NOT_FOUND identique pour un autre compte, 404 PDF_NOT_FOUND). Pages des items base 0 en base, base 1 à l'écran. App (features/pdf/) : LocalPdfStore garde <collegeId>_<jobId>.pdf dans Application Support/pdfs, exclu d'iCloud par le canal natif collega/backup (AppDelegate.swift). File.copy conserve la date du fichier source et la précision est d'1 s : _stamp date chaque nouvelle copie strictement après les autres, c'est ce qui ordonne les versions. Copie dans _afterUploadAccepted, purge dans _loadUserColleges (deleteExcept + keepOnlyServed : pour un import terminé seule la version servie reste ; un collège « prêt » sans version = ancien backend, rien n'est supprimé) et au changement de compte (LocalDataOwner.clearPdfs). Téléchargement background_downloader avec Task.split (chemin relatif, le conteneur iOS change) ; PdfDownloadNotifier ne garde le fichier que si LocalPdfStore.verifyDownload valide l'en-tête %PDF- et la taille annoncée (sinon une page Cloudflare serait « à jour » pour toujours), puis invalide toute la famille collegePdfStatusProvider. purgeLeftovers supprime les .part/.tmp à l'ouverture du store. Limite connue : le jeton d'accès est figé dans la tâche (30 min), pas d'adoption d'un téléchargement terminé app fermée. Sans pdf_version, la ligne dit « indisponible pour l'instant » et le lecteur n'offre aucun bouton. pdfrx épinglé 1.0.103 tant que Flutter 3.27. Drift schéma 10. En widget test, les E/S fichier réelles ne se terminent pas sous testWidgets : store en mémoire.
Evidence: tests « revue finale 1-4 » RED→GREEN ; app tous dossiers verts, backend 962 le 2026-09-26
