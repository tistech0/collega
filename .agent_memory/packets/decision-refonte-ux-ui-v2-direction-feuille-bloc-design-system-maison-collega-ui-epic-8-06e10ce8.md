# Refonte UX/UI v2 : direction « Feuille × Bloc », design system maison Collega UI, epic 8

> Session de cadrage du 2026 09 21/22 branche feat/redesign ux ui, commit 445f759 : la refonte UX/UI de l'app Flutter e…

Session de cadrage du 2026-09-21/22 (branche feat/redesign-ux-ui, commit 445f759) : la refonte UX/UI de l'app Flutter est spécifiée dans `_bmad-output/planning-artifacts/ux-design-specification-v2.md` (remplace la spec d'avril) et découpée dans `epic-8-refonte-ux-ui.md`. Décisions structurantes : (1) nom **Collega** partout, « AppMédecine » disparaît ; (2) navigation à 4 onglets **Aujourd'hui · Bibliothèque · Progression · Profil**, la recherche devient une sheet plein écran hors onglets ; (3) session du jour **unique et mixte** (à revoir de tous les collèges du planning d'abord, puis nouvelles par rang A→B→C), **marquée faite automatiquement à la dernière fiche** — le bouton « Session terminée ✓ » disparaît ; (4) drill plein écran sarcelle, la réponse **glisse par le bas** (pas de flip 3D de l'écran), 3 gestes : swipe gauche = à revoir, haut = bien, droite = maîtrisé, doublés par 3 boutons ; (5) **inscription retirée** (`/auth/register` supprimée du routeur), login seul + mention « Beta privée · accès sur invitation », comptes créés à la main ; (6) design system **maison « Collega UI »** dans `lib/core/ui/` : 14 composants (CgButton, CgTabBar, CgHeader, CgListRow/Group, CgSegmented, CgSheet, CgDrillCard, CgVerdictBar, CgRing, CgRankBar, CgBadge, CgField, CgState, CgSkeleton/CgToast) sur primitives Flutter + Cupertino pour le natif ; **shadcn_ui conservé pendant la migration puis retiré (story 8.15)**, aucun widget Material visible. Direction visuelle retenue « Feuille × Bloc » (maquette `directions-v2/direction-d-fusion.html`) : mise en page listes-à-filets, palette pierre `#ECEAE3` / surface `#F7F6F2` / ink `#17201F` / accent sarcelle `#0E5E63` / accent-soft `#D5E6E4`, états mastered `#0E5E63`, good `#6FA8A2`, review `#D9822B` (texte courant : `#9A5A16`), unseen `#D9D6CC`, danger `#B8352B` ; police **Instrument Sans** (Inter abandonné) ; thème clair unique ; iPhone seul. Prérequis bloquant **story 8.0** : tout item doit avoir un titre — `ItemDetector._extract_chapter` (collega_backend/app/services/ocr/item_detector.py:33) ne cherche que « chapitre X » / « partie X », motif absent des en-têtes type « Item 310 – Tumeurs du testicule », d'où `chapter_title` vide en prod (CNEC) et des listes « Item 310 » sans nom ; correctif = extraction depuis la ligne d'en-tête + référentiel officiel ECN + migration de backfill.
Evidence: Audit de 19 captures iPhone (build main 6d0a0ee) + lecture du code des 8 écrans non capturés : 70 écarts documentés dans `_bmad-output/planning-artifacts/ux-audit-2026-09-21.html` (20 bloquants, 37 gênants, 13 cosmétiques). 3 directions maquettées en HTML interactif et comparées sur l'iPhone par l'utilisateur, écran par écran, avant la fusion.
