# Collega UI (8.2) : règles d'assemblage des composants pour les écrans

> Pour assembler les écrans 8.3+ : importer package:collega app/core/ui/collega ui.dart . CgDrillCard : passer cardKey …

Pour assembler les écrans 8.3+ : importer `package:collega_app/core/ui/collega_ui.dart`. CgDrillCard : passer `cardKey` = identité de l'instance dans la file (ex. '<id>#<passage>') sinon une fiche « à revoir » réinsérée juste derrière elle-même laisserait la carte au verso ; le balayage depuis le bord gauche (20 pt) appelle `onClose` → l'écran doit afficher showCgDialogSheet « Quitter ? » (PopScope désactive le geste retour natif en Flutter 3.27) ; mode définition : `canFlip:false` puis `CgDrillCardState.flip()`. Shell : envelopper le contenu dans `CgTabBarScope` pour que `showCgToast` se place au-dessus de la tab bar (sinon il se pose au ras du bas, cas du drill). CgPage : `reserveTabBar:true` dans les onglets ; gère clavier et safe areas seul. Sheets : sur le navigator racine, fermer avec `Navigator.of(context, rootNavigator: true).pop(v)` ; pied dépendant de l'état → poser `CgSheetFooter` dans le contenu. CgRing dans une liste : `animate:false` (sinon rejoue au défilement). Tout composant animé en boucle doit être statique en mouvement réduit, sinon `pumpAndSettle` des goldens ne se termine pas. Hors widget Material, le DefaultTextStyle de repli souligne en jaune : les styles CgType posent `decoration: none`, l'app fournit un DefaultTextStyle racine (collegaAppBuilder, app.dart, depuis 8.15) et les tests via CgGoldenFrame (cgTestApp). CgPage n'en fournit pas.
Evidence: Revue adversariale 8.2 : 3 bugs reproduits (verdict par balayage retour, clavier, carte figée) + 6 mineurs, tous corrigés avec tests ; 444 tests test/core/ui.
Verified by: Audit mémoire 2026-09-23 contre main 560e503 (lecture du code + tests ciblés verts)
