# Pipeline d'import (chantier 1) : contenu par empreinte, brouillon puis bascule, statut collège = contenu, statut job = import

> Depuis le chantier 1 branche feat/chantier 1 fiabilite imports, spec bmad output/planning artifacts/chantier 1 fiabil…

Depuis le chantier 1 (branche feat/chantier-1-fiabilite-imports, spec _bmad-output/planning-artifacts/chantier-1-fiabilite-imports-spec.md), un import ne touche jamais au contenu en service avant la fin. (1) OCR (ocr_worker.run_ocr) : chaque page est stockée une fois par empreinte (ocr_pages) et rattachée au job (job_pages) — reprise depuis la dernière page ; items détectés → brouillon job_items + item_texts (empreinte = SHA-256 du texte normalisé : lignes de numéros de page, espaces et lignes vides retirés, services/content/fingerprint.py). (2) Génération (services/generation/pipeline.generate_job_items) : pour chaque job_item, génération existante pour (text_hash, GENERATION_VERSION = modèle:version du prompt dans claude_client.py) réutilisée — item inchangé, même PDF chez une autre utilisatrice, tentative précédente —, sinon Claude puis item_generations validée item par item (aucune session ouverte pendant l'appel). (3) Bascule (services/generation/publish.publish_job, une transaction, collège FOR UPDATE, rejouable) : items rapprochés par numéro — inchangé : fiches/ids/pouces/régénérations conservés ; modifié : même item id, fiches remplacées ; nouveau ; disparu. C'est publish_job qui passe job ET collège à generation_complete (l'ancien card_generator a disparu). Quota de réimport rendu si 0 appel Claude. Résumé dans generation_jobs.summary_json. (4) College.status = contenu : reste generation_complete pendant un réimport (l'app garde le collège dans la session du jour) ; /status et le SSE exposent le statut du DERNIER job (+ summary, + reimport pour un échec de réimport). (5) Erreur → services/jobs/job_failure.fail_job (session neuve ; collège failed seulement au premier import) ; interruption (CancelledError, redéploiement) → job laissé actif et repris par ARQ sans repayer ; timeout/jamais repris → cron fail_stale_jobs (30 min sans événement ni updated_at, hors arq:in-progress). Le texte OCR est conservé avec le collège (NFR9 abandonnée) ; purge_unreferenced_content supprime ce que plus rien ne référence.
Evidence: Suite backend 535 tests (dont tests pg sur Postgres réel : bascule, réutilisation, reprise sans repayer, réimport identique de bout en bout 0 appel Claude + quota rendu) ; spike empreintes PNEUMO/CANCERO 100 % stables sur 2 passes OCR.
Verified by: pytest -q (Postgres de test docker-compose.test.yml), 2026-09-23
