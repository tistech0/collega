# Progression collège : les fiches locales sont désormais TOUTES synchronisées (8.3) — la cause « items ouverts seulement » a disparu

> Avant la story 8.3, les fiches n'arrivaient dans Drift qu'à l'ouverture d'un item ItemDetailNotifier → syncCardsToDri…

Avant la story 8.3, les fiches n'arrivaient dans Drift qu'à l'ouverture d'un item (ItemDetailNotifier → syncCardsToDrift), d'où une progression collège fausse (« 0 % · 0 fiches » alors que la barre semblait pleine) et DrillStats.withTotal(serverTotal) pour recaler les non vues. Depuis 8.3, Aujourd'hui synchronise toutes les fiches de chaque collège prêt via GET /v1/colleges/{id}/cards (syncCollegeCards, sans écraser drillLevel/nextReviewAt/reviewCount) : le décompte local est complet dès la première ouverture de l'app en ligne. withTotal reste utile tant que la synchro n'a pas eu lieu (premier lancement hors-ligne). Depuis 8.7, le détail collège (CollegeDetailNotifier) resynchronise aussi toutes les fiches du collège à chaque chargement, et la fin d'un import (_onGenerationComplete) les resynchronise également.
Evidence: test/features/today/today_provider_test.dart « collèges prêts : synchronise toutes leurs fiches » ; prod : 177 + 164 fiches renvoyées par l'endpoint.
Verified by: Audit mémoire 2026-09-23 contre main 560e503 (lecture du code + tests ciblés verts)
