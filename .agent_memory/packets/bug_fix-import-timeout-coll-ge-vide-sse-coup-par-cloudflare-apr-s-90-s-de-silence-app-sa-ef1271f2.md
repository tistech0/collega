# Import "timeout / collège vide" : SSE coupé par Cloudflare après 90 s de silence + app sans reconnexion

> Repro du 2026 09 20 via le tunnel Cloudflare curl resolve + service token : l'upload PNEUMO 67 MB → 202 en 21 s, OCR …

Repro du 2026-09-20 via le tunnel Cloudflare (curl --resolve + service token) : l'upload PNEUMO 67 MB → 202 en 21 s, OCR 88 s avec événements ocr_progress toutes les ~1.5 s, puis card_generation_started et plus rien : Cloudflare ferme le stream SSE GET /v1/colleges/{id}/stream après ~90 s de silence (curl rc 92, stream HTTP/2 fermé) pendant la génération Claude. Côté app, CollegeImportNotifier (collega_app/lib/features/colleges/colleges_import_providers.dart) ne gérait ni onDone ni la reconnexion sur onError : l'état restait figé en ImportStreaming (« timeout » perçu, collège qui paraît vide), et reconnectIfActive (retour au premier plan) ne reconnectait que pour pending/processing, jamais pour ocr_complete (la phase longue). Fix : (a) onDone/onError → _scheduleResync avec backoff exponentiel (base sseReconnectDelayProvider = 3 s, max 30 s, remis à zéro à chaque événement reçu) qui rappelle reconnectIfActive tant que l'état est ImportStreaming ; (b) reconnectIfActive gère pending/processing/ocr_complete → reprise SSE, generation_complete → ImportComplete, failed → ImportError(generation_failed), et re-planifie un resync si /status échoue (réseau). sseReconnectDelayProvider est overridable en test (Duration.zero). Complément côté backend : heartbeat `: keep-alive` toutes les 15 s dans le stream (voir packet décision Cloudflare).
Evidence: Trace du stream via Cloudflare : événements jusqu'à 51 s, puis fermeture à 141 s après 90 s de silence. flutter test test/features/colleges : 45 passed (dont 3 nouveaux tests notifier : ocr_complete reconnecte, failed → erreur, stream coupé → ImportComplete via /status).
Verified by: flutter test test/features/colleges ; curl -sN --resolve … /stream horodaté
