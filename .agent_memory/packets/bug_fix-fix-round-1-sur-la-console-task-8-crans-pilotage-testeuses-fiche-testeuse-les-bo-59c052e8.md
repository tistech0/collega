# Fix round 1 sur la console (task 8, écrans Pilotage/Testeuses/fiche testeuse) : les bouton

> Fix round 1 sur la console task 8, écrans Pilotage/Testeuses/fiche testeuse : les boutons "Copier le message" de test…

Fix round 1 sur la console (task 8, écrans Pilotage/Testeuses/fiche testeuse) : les boutons "Copier le message" de testeuses.js et testeuse.js faisaient `await navigator.clipboard.writeText(text); toast('Message copié')` sans try/catch, laissant une rejection non gérée et aucun retour utilisateur en cas d'échec (justement au moment où un mot de passe provisoire n'est affiché qu'une fois). Corrigé en factorisant un helper partagé `copyText(text)` dans app/static/admin/js/ui.js (juste après toast()) qui essaie writeText, toast 'Message copié' en succès, et toast 'Copie impossible : sélectionne le message et copie-le à la main.' en échec ; les deux vues appellent désormais `onclick: () => copyText(text)`. Convention pour la suite de la console : toute action console qui peut échouer silencieusement (clipboard, API navigateur) doit passer par un helper ui.js qui gère le succès ET l'échec avec un toast, jamais un appel async inline sans catch.
