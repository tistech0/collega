# Formats réels des PDF de collèges (CEP, CNEC) : pièges de l'ItemDetector et où relire le texte

> Les PDF de collèges n'ont pas un format unique. CEP Pneumologie 2023 : page d'en tête « Item 75 \n Addiction au tabac…

Les PDF de collèges n'ont pas un format unique. CEP (Pneumologie 2023) : page d'en-tête « Item 75 \n Addiction au tabac. \n Rang Rubrique Intitulé », titre sur 1-2 lignes (continuation en minuscule), parfois en CAPITALES, parfois un seul mot (Pneumothorax), lettrine cassée possible (338 « Œ Q A / DEME DE UINCKE » → comblé par un libellé official) ; chaque item de PNEUMO contient aussi 12 fois un filigrane « diffusé exclusivement… SBA-MEDECINE » (envoyé à Claude, tokens payés). CNEC (Cancérologie 4e éd.) : « Item 290 » est un EN-TÊTE COURANT répété sur chaque page ; le titre est dans « OBJECTIFS: N° 304. Titre » (variantes « OBJECTIFS : », « N"o300. ») ; le sommaire p2-3 « Chapitre 18 : Titre ..... 307 \n Item 308 » ressemble à un en-tête ; « . Item 313 » (ponctuation OCR) doit être détecté ; « tem 30 » = en-tête tronqué (ne pas tolérer « tem »). Les textes d'items contiennent les numéros de page imprimés (jusqu'à 23 lignes « 233 » par item) : l'empreinte d'item les ignore (services/content/fingerprint.py). Relire le texte : depuis le chantier 1 il est conservé en base (ocr_pages / item_texts, plus de purge à 24 h) ; pour les imports antérieurs, relire le PDF sur le volume /tmp/collega_pdfs/{college_id}_{job_id}.pdf dans collega-worker-1 (python -m scripts.backfill_content_store ou scripts.backfill_item_titles, -m obligatoire). Un PDF corrompu (ex. ANAPATH 4e.pdf local : startxref qui pointe au milieu des données) est refusé à la réception (422 PDF_DAMAGED).
Evidence: Essais sur les PDF de prod (CEP ed9a1032, CNEC 4ab16fc4, 44/44 items titrés le 2026-09-22) ; spike empreintes du 2026-09-23 (numéros de page dans les items, filigrane PNEUMO) ; ANAPATH illisible par pdfminer (No /Root object).
Verified by: SQL prod après migration 015 + spike local pdfplumber/ItemDetector 2026-09-23
