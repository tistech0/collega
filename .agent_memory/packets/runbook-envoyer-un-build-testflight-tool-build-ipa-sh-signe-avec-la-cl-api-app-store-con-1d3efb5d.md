# Envoyer un build TestFlight : tool/build_ipa.sh signe avec la clé API App Store Connect (compte Apple individuel)

> Le compte Apple Developer de la beta est un compte individuel titulaire Jérôme Lesur, Team ID E3BNB5L3X9 : impossible…

Le compte Apple Developer de la beta est un compte individuel (titulaire Jérôme Lesur, Team ID E3BNB5L3X9) : impossible d'y être membre dans Xcode. collega_app/tool/build_ipa.sh signe donc sans compte Xcode : flutter build ios --config-only (dart-define Cloudflare de .env.local, build number = minutes depuis 2026-01-01) puis xcodebuild archive/exportArchive avec -allowProvisioningUpdates et la clé API (ASC_KEY_ID / ASC_ISSUER_ID dans collega_app/.env.local, clé dans ~/.appstoreconnect/private_keys/AuthKey_<id>.p8), puis xcrun altool --upload-app. `--no-upload` construit seulement. Bundle ID : com.matthislesur.collega (iOS, Android, APNS_BUNDLE_ID) ; app App Store Connect id 6816380922. Un binaire refusé par App Store Connect (mail ITMS) n'apparaît jamais dans TestFlight → Builds. Premier refus ITMS-90683 : file_picker embarque DKImagePickerController (PHPhotoLibrary), il faut NSPhotoLibraryUsageDescription et NSPhotoLibraryAddUsageDescription dans Info.plist (test test/core/ios_release_config_test.dart). L'état de traitement d'un build se lit par l'API (JWT ES256, GET /v1/builds?filter[app]=6816380922). Clé APNs (Key ID B8AMX8Z69C) sur le NAS dans /mnt/user/appdata/collega/secrets (uid 1000, mode 400), montée en lecture seule sur /run/secrets/collega par docker-compose.prod.yml.
Evidence: Build 386538 envoyé puis refusé (ITMS-90683) ; build 386550 envoyé avec « UPLOAD SUCCEEDED » après ajout des phrases photothèque ; IPA inspectée : aps-environment production, E3BNB5L3X9.com.matthislesur.collega
