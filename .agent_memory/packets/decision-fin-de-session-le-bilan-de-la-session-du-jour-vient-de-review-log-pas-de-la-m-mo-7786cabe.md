# Fin de session : le bilan de la session du jour vient de review_log, pas de la mémoire

> DrillEndScreen story 8.5 affiche le bilan d'une session du jour reprise : à la reconstruction de la session, DrillNot…

DrillEndScreen (story 8.5) affiche le bilan d'une session du jour reprise : à la reconstruction de la session, DrillNotifier (drill_providers.dart) recharge les évaluations depuis DailySessionRepository.lastVerdicts(day), qui ne lit que les lignes review_log daily = true ; sinon le score n'aurait que les fiches jugées après la reprise. Depuis la 8.8, toute révision est journalisée dans review_log, y compris « Refaire les à revoir » (replayingErrors), mais avec daily = false (daily: arg.isDailySession && !_replayingErrors) : lastVerdicts/verdictCounts l'ignorent, donc le bilan du jour reste celui de la vraie session ; la même garde empêche _persistDaily d'écraser la file enregistrée. Le budget « Demain · N fiches » vient de TodayReady.tomorrowBudget (le réglage), pas de la taille de la session du jour. Les titres d'items sont lus dans Drift (DrillRepository.itemTitles, pas d'appel réseau) via un FutureBuilder : hors-ligne ne bloque pas la fin. total == 0 (fiches disparues après réimport) → état « Aucune fiche à réviser », sans score ni haptique.
