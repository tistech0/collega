# Série de l'Accueil : calculée sur le téléphone (streakLength + quiet_days, schéma drift 9)

> La série « N jours d'affilée » de l'onglet Aujourd'hui vit uniquement sur le téléphone ne suit ni changement d'iPhone…

La série « N jours d'affilée » de l'onglet Aujourd'hui vit uniquement sur le téléphone (ne suit ni changement d'iPhone ni réinstallation). streakLength(today, completed, excused) est une fonction pure : jour compté = ligne daily_sessions avec completedAtMs ; aujourd'hui non terminé ne casse pas (on compte depuis hier) ; jours excusés = quiet_days ∪ PlanningState.postponedDays (ne cassent pas, ne comptent pas). La table drift quiet_days (migration 8 → 9) enregistre les jours « rien à réviser » car DailySessionRepository._build supprime la ligne du jour quand plan.isEmpty ; elle n'est remplie que si custom == false (un filtre « Personnaliser » vide n'est pas un jour calme) ; resetDay et deleteEverything la vident. Badge affiché dès kStreakMinShown = 2. L'animation « Session faite » se joue une fois : _TodayScreenState._start pose _celebrate au retour du drill si la session est passée de non terminée à terminée, et DoneCheck n'anime qu'à sa création (animate ignoré ensuite, jamais si MediaQuery.disableAnimations).
