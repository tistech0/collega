# Collega UI : police embarquée, goldens, Widgetbook web, contrastes (à jour 8.15)

> 1. Fonts: Instrument Sans is bundled in collega app/assets/fonts static 400 700 instances ; google fonts is no longer…

1. Fonts: Instrument Sans is bundled in collega_app/assets/fonts (static 400-700 instances); google_fonts is no longer a dependency. In tests, load the font with test/support/cg_fonts.dart, otherwise text renders in Ahem.
2. Goldens: use cgGoldenMatrix / cgGoldenWidths × cgGoldenScales (375/393/430 × 1.0/1.6). Regenerate each test folder with --update-goldens and look at the 1.6× PNG.
3. Widgetbook: lives in collega_app/widgetbook as a separate package, targets the web, and redeclares the font family.
4. Contrast: contrast_test.dart is the source of truth. Since 8.15, all text (including ink3: section titles, row values, footnotes, tab labels) must reach 4.5:1 on ground, surface and soft. ink2 is #454D4C and ink3 is #60645E; they must stay at least 1.4:1 apart. rankB is #4C696D, rankC is #64635B, and text on review uses ink (onReview).
5. The five core screens (Today, Library, Drill, Progress, Profile) have a test asserting labeledTapTargetGuideline, iOSTapTargetGuideline and textContrastGuideline. The goldens frame paints the ground itself, so an accessibility or background bug can be hidden in goldens: check the background painted by the screen itself.
6. The app is a technical MaterialApp.router themed by buildCgMaterialTheme plus cupertinoOverrideTheme; shadcn_ui is removed. Flutter 3.27 has no Color.toARGB32.
Verified by: flutter test test/core/ui (449) + 5 core screen a11y tests; reverting ink3 to #838880 makes Today/Library/Progress a11y tests fail
