# Import : avancement de génération (migrations 016-017) et écrans 8.13

> La génération n'écrit ses fiches qu'à la fin une transaction : pour « N fiches prêtes » au fil de l'eau, CardGenerato…

La génération n'écrit ses fiches qu'à la fin (une transaction) : pour « N fiches prêtes » au fil de l'eau, `CardGenerator(progress_reporter=report_generation_progress)` publie, après chaque item, items traités / total / fiches / 3 dernières questions dans `colleges.generation_items_done|_total|_cards|_preview` via une session séparée (commit immédiat, échec isolé ; pas de conflit de verrou avec la transaction de génération). Le flux SSE émet `generation_progress` (seulement en `ocr_complete` et si la valeur change) ; l'OCR remet ces colonnes à zéro à chaque import. App : `ImportStreaming.itemsDone/itemsTotal/cards/preview`, `ImportUploading.refId`, `pdfPickerProvider` (fichier + taille, aucune lecture disque en test), `importErrorMessage` (phrases, « Tes fiches restent » en réimport). Fin d'import → `/colleges/:ref` ; le détail n'agit pas tant que la liste des collèges se recharge (sinon renvoi vers l'import). Tests widget : jamais de vraie E/S fichier dans testWidgets (FakeAsync bloque).
