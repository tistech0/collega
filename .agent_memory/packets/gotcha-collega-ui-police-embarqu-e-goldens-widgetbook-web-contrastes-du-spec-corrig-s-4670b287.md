# Collega UI : police embarquée, goldens, Widgetbook web, contrastes du spec corrigés

> Story 8.1. 1 Instrument Sans est EMBARQUÉE collega app/assets/fonts, instances statiques 400 700 générées avec fontTo…

Story 8.1. (1) Instrument Sans est EMBARQUÉE (collega_app/assets/fonts, instances statiques 400-700 générées avec fontTools varLib.instancer depuis la police variable Google Fonts) — pas google_fonts au runtime (hors-ligne + goldens). Dans les tests, charger la police via test/support/cg_fonts.dart (FontLoader), sinon rendu Ahem. (2) Goldens : utiliser cgGoldenMatrix(name, builder, height:) de test/support/cg_golden.dart → 6 PNG (375/393/430 × 1,0/1,6), animations réduites ; régénérer avec --update-goldens et REGARDER le PNG à 1,6× (mots coupés, troncatures). (3) Widgetbook vit dans collega_app/widgetbook (paquet séparé, widgetbook 3.15.0 compatible Flutter 3.27) et cible le WEB : le build macOS/iOS échoue au pod install à cause des plugins de l'app ; les polices d'un paquet racine ne sont pas exposées aux paquets dépendants → widgetbook/pubspec redéclare la famille avec ../assets/fonts. (4) Les hex du spec v2 violaient ses propres seuils : ink3 → #838880, rankB → #4C696D, rankC → #64635B, texte sur review = ink (onReview) ; test/core/ui/tokens/contrast_test.dart fait foi. (5) ShadApp.router n'a pas cupertinoThemeBuilder : accent Cupertino via ThemeData.cupertinoOverrideTheme dans materialThemeBuilder. (6) Flutter 3.27 : pas de Color.toARGB32 (utiliser .value).
Evidence: flutter test test/core : 88 verts ; widgetbook flutter build web OK, build macos KO (pods) ; goldens inspectés à 1,6×.
