# Sheets (routes sans page) et GoRouter : go() ne les ferme pas ; recherche = sheet, extrait serveur = phrase entière

> Les sheets Collega showCgSheet sont des routes SANS page poussées sur le Navigator racine de GoRouter : elles s'accro…

Les sheets Collega (`showCgSheet`) sont des routes SANS page poussées sur le Navigator racine de GoRouter : elles s'accrochent à la page en dessous (souvent la page du ShellRoute). Conséquences vérifiées en 8.10 : (1) une page GoRouter poussée depuis la sheet (drill `/drill`) s'empile AU-DESSUS de la sheet ; `pop` y ramène (« Retour à la recherche ») ; (2) `context.go('/home')` garde la page du shell, donc la sheet reste ouverte → pour tout fermer, dépiler le drill puis les routes sans page (`popUntil(route.settings is Page)` après la page du drill) avant `go` (drill_end_screen `_finish`) ; (3) une route du ShellRoute (détail d'item) poussée depuis la sheet serait DESSOUS : fermer la sheet d'abord, pousser ensuite (search_sheet `_open`). Rouvrir une sheet après la fermeture d'une page : `Navigator.of(context, rootNavigator: true).overlay.context` + post-frame (item_detail `_reopenSearch`, via `PopScope` pour couvrir le balayage iOS). Côté serveur, `ts_headline` ne rendait souvent que le mot : `build_excerpt` (full_text_search.py) rend la phrase de la réponse (verso) contenant les termes surlignés.
Verified by: test drill_end_screen « Terminer ferme aussi la sheet » + search_sheet_test + item_detail_screen_test ; prod : extraits « alcool » / « BNP »
